Key capabilities

Core features that matter most

01

Structured log ingestion

Upload UTF-8 text or newline-delimited JSON security logs up to 3 MB and analyze them locally.

02

Entity extraction

Detect IP addresses, usernames, URLs, hashes, and other indicators from raw evidence.

03

Deterministic detection

Correlate authentication failures in a 10-minute window and detect suspicious PowerShell, ransomware indicators, and known malicious strings.

04

Risk scoring

Assign a consistent 0–100 risk score and map each finding to a clear severity tier.

05

Incident case tracking

Create, view, and manage case records with structured evidence, status, and source metadata.

06

Queue filtering

07

Workflow updates

Update a single case inline or apply bulk status changes to multiple selected incidents.

08

Investigation notes

Record assignees and investigation notes so analysts can track actions and ownership.

09

Evidence export

Export filtered incident data as CSV or JSON and surface more detailed reporting for stakeholders.

10

Local-first security

Keep evidence handling local, transparent, and operational without requiring external AI or hosted services.
